# Retail Sales Data Dashboard

A Business Intelligence project built using Excel, MySQL, and Power BI to analyze retail sales performance, profitability, customer behavior, and regional trends.

---

# Project Overview

This project focuses on transforming raw retail sales data into meaningful business insights through data cleaning, SQL analysis, and interactive dashboard development.

The dashboard helps businesses monitor:

* Sales performance
* Profitability
* Product trends
* Regional performance
* Shipping analysis
* Customer segments

---

# Tools & Technologies Used

* Microsoft Excel
* MySQL
* Power BI

---

# Dataset

Dataset Source:
Kaggle Superstore Retail Dataset

Dataset contains:

* Sales data
* Customer information
* Product details
* Shipping details
* Regional information
* Profit and discount analysis

Total Records:

* Approximately 9,994 rows

Data Cleaning in Excel

# Data Cleaning

Performed using Excel:

* Removed duplicate records
* Handled missing values
* Standardized column names
* Corrected data types
* Created calculated columns:

  * Year
  * Month Name
  * Shipping Days
  * Profit Margin

---

# SQL Analysis

SQL queries were used to analyze:

* Total Sales
* Total Profit
* Sales by Region
* Product Performance
* Profitability Analysis
* Shipping Analysis
* Customer Segment Analysis

# Power BI Dashboard Features

The interactive dashboard includes:

## KPI Cards

* Total Sales
* Total Profit
* Total Orders
* Profit Margin %

## Visualizations

* Monthly Sales Trend
* Sales Distribution by Ship Mode
* Most Profitable Categories
* Top 10 Products by Sales

## Interactive Filters

* Year Slicer
* Region Slicer

---

# Key Business Insights

* Technology category generated the highest sales and profit.
* Sales increased significantly during year-end months.
* Standard Class shipping contributed the highest sales share.
* High discounts negatively impacted profitability.
* Consumer segment generated the highest overall sales.
